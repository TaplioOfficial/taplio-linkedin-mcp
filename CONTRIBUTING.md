# Contributing

Thanks for your interest in the Taplio LinkedIn MCP Server documentation.

This repository is documentation-first: it describes the hosted, remote Taplio MCP Server and the tools it
exposes. The server itself is operated by Taplio and is not built from this repository.

## What you can contribute

- Fixes to the tool reference (parameters, defaults, limits) when they drift from the live server.
- Clearer installation instructions for additional MCP hosts.
- Better examples, workflows, and troubleshooting notes.

## How to contribute

1. Open an issue describing the problem or improvement.
2. For documentation changes, open a pull request against `main`.
3. Keep the tool tables in `README.md` and `docs/tools.md` in sync.

## Style

- Plain, keyboard-friendly characters only. No em or en dashes, no curly quotes, no unicode bullets or arrows.
- Use regular dashes and straight quotes.
- Keep parameter tables aligned with the actual JSON Schema of each tool.

## Reporting server or product issues

Bugs in the Taplio product, LinkedIn publishing, or account access are handled by Taplio support, not here.
Use this repository only for documentation of the MCP interface.
